# Description:
Evaluate one learned handover decision policy against a configured signal-based baseline in a reproducible cellular simulator.

# Challenge:
Evaluate a learned handover decision policy against a conventional signal-based baseline in a reproducible cellular-network simulator. Study how the learned policy performs for users moving at different speeds across multiple cells.

# Key Requirements
- Use one working LTE/5G-capable simulator.
- Configure 3 cells and 2 user-mobility speeds.
- Implement 1 supervised learning model for handover decisions.
- Compare it against a signal-based baseline.
- Run experiments using multiple random seeds.
- Measure:
  - Handover failures
  - Ping-pong events
  - Interruption duration
  - Throughput
- Clearly identify the implemented LTE/5G radio model.
- No 6G standards-conformance claim, new radio stack, deep-RL requirement or field deployment.

# Expected Outcome
- Reproducible cellular simulation scenarios
- Signal-based baseline implementation
- Learned handover decision model
- Multi-seed evaluation results
- Comparison of handover reliability, interruption and throughput
- Performance analysis and visualisations
- Final technical report and demonstration
